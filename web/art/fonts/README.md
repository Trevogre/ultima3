# Fonts

`IMFeENrm28P.ttf`: IM FELL English Roman, Igino Marini's revival of the
Fell types, under the SIL Open Font License 1.1 (`OFL-imfellenglish.txt`).
The Ultima V port sets its dateline in it, and so does the Steam artwork
here: "1983 ~ 2026" (`tools/steam-art.mjs`). It is used only to make that
artwork; the game does not load it.
